Amazon Q Developer Plugin Is Gone —
Here's How to Use Kiro

Step-by-step migration from Amazon Q Developer to Kiro CLI in Android Studio and JetBrains IDEs via the Agent Client Protocol.

Amazon recently announced the end of support for the Amazon Q Developer plugin for Android Studio and other JetBrains IDEs. If you've been relying on it for inline suggestions, chat, and code generation, you're probably wondering what comes next.

The answer is Kiro — Amazon's next-generation AI coding assistant. It's available as a standalone IDE (built on VS Code) and as a CLI that plugs directly into JetBrains IDEs through the Agent Client Protocol (ACP). This means you can keep using Android Studio, IntelliJ IDEA, PyCharm, or any other JetBrains IDE and still get full AI-assisted development — with more capabilities than Q Developer ever offered.

Why the Change?

Amazon Q Developer's IDE plugins for JetBrains are no longer receiving updates. Amazon's official recommendation is to migrate to Kiro, which brings everything Q Developer had plus several new capabilities:

How It Works

Kiro integrates into JetBrains IDEs through JetBrains AI Assistant and the Agent Client Protocol (ACP). ACP is an open standard (think LSP, but for AI agents) that lets any compatible agent communicate with any compatible editor. Kiro CLI implements ACP, so once you wire it up, Kiro's full agentic capabilities — file editing, terminal commands, MCP servers, skills, subagents — are available right inside your IDE's AI Chat window.

Step-by-Step Setup

Step 1

Uninstall Amazon Q Developer

  1. Open Settings → Plugins → Installed
  2. Find Amazon Q (or Amazon Q Developer)
  3. Click Uninstall
  4. Restart the IDE
Step 2

Install Kiro CLI

Follow the official installation guide for your platform. After installation, verify it's working:

which kiro-cli

Take note of the full path — you'll need it in step 5. It's typically ~/.local/bin/kiro-cli on macOS and Linux.

Step 3

Sign In to Kiro

kiro-cli auth login

You can authenticate with GitHub, Google, AWS Builder ID, or IAM Identity Center.

Step 4

Install JetBrains AI Assistant

  1. In your JetBrains IDE, go to Settings → Plugins → Marketplace
  2. Search for "AI Assistant" and install it
  3. Restart the IDE
AI Assistant is available for all JetBrains IDEs including Android Studio, IntelliJ IDEA, PyCharm, WebStorm, GoLand, and others. See the official AI Assistant docs for details.
Step 5

Add Kiro as a Custom Agent

  1. Open the AI Chat tool window
  2. Click the ⋮ (three dots) or the settings icon
  3. Select Add Custom Agent
  4. This opens the ACP configuration file (~/.jetbrains/acp.json). Add the following:
{
  "agent_servers": {
    "Kiro Agent": {
      "command": "/full/path/to/kiro-cli",
      "args": [
        "acp"
      ]
    }
  }
}

Replace /full/path/to/kiro-cli with the actual path from step 2. For example:

  • macOS/Linux: /home/youruser/.local/bin/kiro-cli
  • macOS (Homebrew or similar): check with which kiro-cli
Why the full path? JetBrains IDEs don't always inherit your shell's PATH, so a bare kiro-cli command may not be found. Always use the absolute path.
Step 6

Start Using Kiro

  1. Open the AI Chat tool window
  2. In the agent/mode selector dropdown, choose "Kiro Agent"
  3. Start chatting

That's it. You now have Kiro's full capabilities inside your JetBrains IDE.

Troubleshooting

Kiro Agent doesn't appear in the dropdown
• Double-check that ~/.jetbrains/acp.json is valid JSON (no trailing commas, correct quotes)
• Verify the kiro-cli path is correct by running it directly in your terminal
• Confirm you're signed in: kiro-cli auth status
• Restart the IDE after editing acp.json
Something isn't working as expected
Check the ACP logs. On macOS:
$TMPDIR/kiro-log/kiro-chat.log
On Linux:
$XDG_RUNTIME_DIR/kiro-log/kiro-chat.log
For verbose output:
KIRO_LOG_LEVEL=debug kiro-cli acp

What About VS Code Users?

If you use VS Code, you don't need the CLI route. Kiro IDE is a standalone editor built on VS Code that imports your extensions, themes, keybindings, and settings directly. On first launch it will prompt you to import your VS Code profile. See the VS Code migration guide for details.

What About the Q Developer CLI?

If you were using Amazon Q Developer in the terminal (not the IDE plugin), there's a separate migration path. See Upgrading from Q CLI for command changes and configuration migration.
